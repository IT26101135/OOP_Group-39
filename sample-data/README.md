Owner: IT26101132 - Vehicles and Sample Data. Snapshot: 10 November 2026.
These fictional records are generated by DemoDataSeedRunner. They do not represent real school operations, registrations, identities or contact details.

**Existing data-demo folders retain the old names and records. Use a fresh empty data folder for the new loader. Never delete or overwrite live data to refresh a seed.**

Phone fixtures use a deliberately non-dialable +94/zero-prefix pattern accepted by the app's 7-15-digit syntax check. NICs use an impossible zero-prefix civil identity pattern accepted by its 12-digit syntax check. They are not valid allocated phone numbers or civil identities. Emails use reserved .test domains; student addresses are invented. Instructor licence numbers and qualifications are left empty rather than inventing accreditation claims.

## Run a fresh snapshot copy

Open a fresh PowerShell shell with Java 17 selected. Copy all records and counters together, and leave both seed loaders off:

```powershell
$snapshotRunDirectory = Join-Path $env:TEMP ("drivespark-snapshot-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path $snapshotRunDirectory | Out-Null
Get-ChildItem -LiteralPath .\sample-data -Filter '*.txt' | Copy-Item -Destination $snapshotRunDirectory
$env:DRIVESPARK_DEMO_SEED_ENABLED = "false"
$env:DRIVESPARK_ADMIN_SEED_ENABLED = "false"
$env:APP_DATA_DIRECTORY = $snapshotRunDirectory
try { .\mvnw.cmd spring-boot:run }
finally {
    Remove-Item Env:DRIVESPARK_DEMO_SEED_ENABLED, Env:DRIVESPARK_ADMIN_SEED_ENABLED,
        Env:APP_DATA_DIRECTORY -ErrorAction SilentlyContinue
}
```

Open http://localhost:8080/. Stop the app before leaving the shell. The snapshot has fixed dates: seed-disabled runs do not refresh them. For dates relative to today, use the main README's loader instructions with a fresh empty folder. Do not describe stale snapshot lessons as future appointments.
