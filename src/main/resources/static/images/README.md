# Image assets

The current logo, favicon, and night-road hero are local SVG files and do not require network access. If real photos are added, use `/static/images/hero.jpg`, `/static/images/about.jpg`, and `/static/images/instructors/<name>.jpg`. Provide meaningful alt text, explicit width and height, lazy loading below the fold, and a dark bottom gradient overlay wherever text is placed over a photo. Keep a gradient initials avatar as the fallback when an instructor photo is absent.
